# Тестирование веб-приложения «Яндекс.Самокат»

## О проекте
Комплексное тестирование веб-приложения «Яндекс.Самокат»: функциональность, вёрстка, API и мобильные нотификации.

## Что тестировалось
- **Веб-приложение** — экран «Статус заказа», форма оформления заказа
- **Мобильное приложение** — пуш-нотификации, обработка отсутствия интернета
- **API** — создание/удаление курьера, получение заказа по треку

## Инструменты
- **Браузеры:** Яндекс Браузер (26.4.3.894), Google Chrome (148.0.7778.217)
- **API:** Postman
- **Мобильное:** Android Studio (Pixel 4a, Android 11)
- **Макеты:** Figma
- **Документация:** Google Таблицы
