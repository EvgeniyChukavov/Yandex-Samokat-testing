# Тестирование API

## Описание проекта
Проведено тестирование API приложения с использованием Postman. Разработан чек-лист для проверки API по требованиям к бэкенду.

## Что сделано
- Изучены требования к бэкенду и документация к API
- Разработан чек-лист для тестирования API (48 проверок)
- Проведено тестирование API с использованием Postman
- Проверена валидация полей: login, password, firstName
- Проверено удаление курьера и связанных заказов
- Проверено получение заказа по номеру отслеживания
- Заведены баг-репорты по найденным дефектам

## Инструменты
- Postman — отправка запросов, проверка ответов
- SQL — проверка записей в БД

## Результат
- Чек-лист проверки API (48 проверок)
- Баг-репорты по API (16 багов)
- Проверка создания и удаления курьеров
- Проверка получения заказа по номеру отслеживания
