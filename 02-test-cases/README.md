# Тест-кейсы для функциональности и вёрстки

## Описание проекта
Спроектированы тест-кейсы на функциональность веб-приложения «Яндекс.Самокат» и вёрстку по макетам в Figma. Проведено тестирование по составленным тест-кейсам.

## Что сделано
- Спроектированы тест-кейсы на функциональность (экран «Сделать заказ»)
- Разработаны тест-кейсы на вёрстку по макетам в Figma
- Проведено тестирование по тест-кейсам
- Заведены баг-репорты по найденным дефектам
- Составлена таблица валидации полей формы заказа
- Проведено тестирование нотификаций мобильного приложения

## Инструменты
- Figma — работа с макетами
- Google Таблицы — ведение тест-кейсов
- Android Studio — тестирование мобильного приложения

## Результат
- Таблица валидации данных
- Тест-кейсы для нотификаций (30 проверок)
- Баг-репорты по найденным багам

## Файлы
- `validation-data.md` — таблица валидации полей
- `test-cases-notifications.md` — тест-кейсы для нотификаций
