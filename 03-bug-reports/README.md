# Баг-репорты по результатам тестирования

## Описание проекта
Задокументированы баги, найденные в ходе тестирования веб-приложения, мобильного приложения и API.

## Что сделано
- Выявлены баги при тестировании веб-приложения
- Задокументированы баги мобильного приложения (нотификации, интернет-соединение)
- Найдены дефекты API (валидация полей, удаление курьера)
- Описаны шаги воспроизведения, ожидаемый и фактический результат

## Инструменты
- Google Таблицы — ведение баг-репортов
- Postman — тестирование API
- Android Studio — тестирование мобильного приложения

## Результат
- Баг-репорты по веб-приложению (24 бага)
- Баг-репорты по мобильному приложению (8 багов)
- Баг-репорты по API (16 багов)

## Файлы
- `bug-reports-web.md` — баг-репорты веб-приложения
- `bug-reports-mobile.md` — баг-репорты мобильного приложения
- `bug-reports-api.md` — баг-репорты API
