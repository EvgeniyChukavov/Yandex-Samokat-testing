# Чек-листы для тестирования приложения «Яндекс.Самокат»

## Описание проекта
Проведено тестирование функциональности веб-приложения «Яндекс.Самокат» (учебный тренажёр). Составлен чек-лист из 84 проверок по экрану «Статус заказа».

## Что тестировалось
- **Валидация поля ввода** — поиск заказа с существующим, несуществующим номером, пустым полем, буквами и спецсимволами.
- **Статусы заказа** — отображение и активация статусов от «Самокат на складе» до «Время аренды кончилось».
- **Визуальное состояние статусов** — пройденные, активные и неактивные статусы.
- **Отмена заказа** — работа кнопки, всплывающие окна, поведение после отмены.
- **Перенос текста** — длинные имена, фамилии, адреса.
- **Элементы интерфейса** — шапка, поле ввода, кнопки.
- **Вёрстка данных заказа** — отображение данных после поиска.
- **Вёрстка цепочки статусов** — цифры, подписи, цвета.
- **Вёрстка окна «Хотите отменить заказ?»** — расположение, цвета, шрифты.
- **Соответствие данных заказа** — данные в карточке соответствуют введённым.
- **Логика активации статусов** — какой статус активен в зависимости от состояния заказа.

## Инструменты
- **Яндекс Браузер** (версия 26.4.3.894, 1920x1080)
- **Google Chrome** (версия 148.0.7778.217, 1280x720)
- **Google Таблицы** — ведение чек-листа
- **Figma** — работа с макетами
